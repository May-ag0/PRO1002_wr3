# PRO1002 – Work Requirement 3

## Project Description
This repository contains my solution for work requirement 3. The small Python script uses the socket module to resolve a hostname into an IP address and displays the result in the terminal. 


## Reflection
In Module 5, I learned how web browsers and servers communicate using HTTP. The browser sends requests to the server, which processes them and returns responses. The browser then interprets and renders the content so users can view and interact with it. I also learned that TCP/IP enables data transmission across networks, while the Socket API allows programs to access networking functionality. 

One challenge was understanding how the different networking technologies work together, particularly the relationship between TCP/IP, HTTP, and the Socket API. While their individual purposes were relatively straightforward, understanding how they interact in practice required more attention. So I would like to explore further how these technologies work together in practice.
